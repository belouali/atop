# Parked analyses

Scripts for analyses that were run but are not reported in the manuscript.
They are kept for provenance and are not part of the reproduction steps in
the main README.

- `make_fig_s2.py`: candidate-pattern count as a function of the support threshold.
- `make_fig_s6.py`: masking versus within- and across-visit shuffle controls
  (superseded by `scripts/make_fig_s10_masking.py`, masking only).
- `rerun_perturbation_per_patient.py`: per-patient rerun of the 266-pattern
  perturbation analysis.
- `parked_supplement_blocks.py`: the supplementary text and table blocks that
  accompanied these analyses.
